NEO WEB DESIGNER — PREMIUM THREE-DEMO EDITION
================================================

FILES
- index.html : Main agency website and portfolio
- style.css  : Main styling and shared demo styles
- script.js  : Mobile navigation and reveal animation
- demo1.html : Aurelia & Co. — luxury private advisory
- demo2.html : FORMA Objects — e-commerce concept with working demo add-to-bag counter
- demo3.html : Flux — modern technology/SaaS landing page

HOW TO OPEN
1. Extract this ZIP into a normal folder.
2. Keep all six HTML files, CSS, and JS in the same folder.
3. Double-click index.html to open the main agency website in your browser.
4. Click any portfolio preview or “Explore live demo”. Each demo has a “Back to NEO Portfolio” link.
